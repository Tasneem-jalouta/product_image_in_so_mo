Product Image in Sale Order & MRP

Enhance your Sales & Manufacturing workflow with product images in order lines.
This module adds product images to Sale Order Lines and Manufacturing Orders, providing visual clarity and improving user experience for sales and production teams.

✔ Key Features

  • Display product image automatically in Sale Order lines.
  • Show product image inside MRP Production Order components.
  • Helps sales teams verify product selection visually.
  • Reduces errors in production by providing image-based confirmation.
  • Lightweight module — no impact on system performance.
  • Fully compatible with Odoo 17.
  • No configuration required — install and use instantly.

⚙️ Installation

  • Download the module ZIP file.
  • Upload it through Odoo Apps → Install.
  • Ensure the required apps are installed: Sales, MRP, Product.
  • No additional configuration needed.
